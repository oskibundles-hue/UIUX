The grade

Carried over from the older Deliverables page, which this one now replaces.

One look, matched per clip from the D-Log M originals to your colour-corrected master. Nothing else was applied.

Reference
Dropbox › 03 Grade Reference › 2026-09-06 color corrected master - grade reference.mov (previous reference in _previous/)
How it is matched
Per-channel histogram match plus grey-point neutralise, per clip, against 11 frames of the reference (scripts/match_grade.py)
Grey point
Reference +5.7 red-minus-blue, slightly green; the 18 clips land +4 to +8 except 02 and 08, which sit cooler (−0.1 and +1.0)
Base LUT
luts/AK_NQ_Signature.cube is the older published look; the new reference is now the default for every cut
Captions
Anton, 0.80 width, #FDFDFD base, #FBD101 active word, centre 72.6% down frame
Vlog Cut variant
Re-graded from the D-Log raws: 85% tone match, grey point +2.0 R−B (was +5.7), black lift 0.03, highlight knee 0.08, saturation 92%, no sharpening
