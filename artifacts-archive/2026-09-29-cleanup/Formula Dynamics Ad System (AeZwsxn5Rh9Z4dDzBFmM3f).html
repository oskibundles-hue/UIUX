02 — The repair

The logo was soft

The kit traced its logo artwork out of the brand-guide raster, where the lockup is 596×250px and the FD mark just 149×114px — then blurred it 0.7px before tracing. Corners came out rounded; the monogram looked melted at end-card size.

Re-tracing from the supplied master artwork — transparent background, exact brand hexes — closed the gap almost entirely.

8.71% Shipped — mean error vs master
0.84% Re-traced — the anti-aliasing floor

0.84% is as close as a traced vector gets to an anti-aliased raster — it is measurement noise, not error. All four lockups, four variants and three PNG widths were rebuilt from it, then 254 overlay and template files, ten download bundles, the printable brand guide and the asset index.

And the stripe had five segments

Reading the master turned up a second error. The accent stripe was specified as four segments; the artwork has five — red 36.7%, black 21.4%, white 19.4%, green 17.0%, yellow 5.5%. It carries both a black and a white segment, and whichever matches the background reads as a gap. That is why it looked like four.

The rule under this page's masthead is that stripe, at true proportions. The gap left of centre is the black segment.

03 — The system

Three axes, one file format

Every version is a cue file — copy, beat timings, layout fractions and the grade. The three axes stay separate on purpose: a test on one axis stays interpretable. build_ad.py --all renders the lot.

layouts/

Same video,
different design

Four treatments, swappable by name. Each supplies four draw functions.

  • hud — approved
  • centred — approved
  • panel — busy footage
  • rail — unsigned

cuts/

Different
videos

Shot-level re-editing. A re-cut is a list of shot ids, not timecodes.

  • base — 14.04s
  • detail-walk — 11.24s
  • 6s-preroll — 6.04s

variants/

Same video,
different message

Only hook and CTA change, so a test isolates message from edit.

  • a — book your build
  • b — get a quote
  • c — engagement
  • d — fitment
Re-cutting was the half the kit was missing. AUTO-EDIT.md is explicit that the overlay tool does not cut footage — it decorates a clip you already cut. recut.py now trims and concatenates shots into a new plate, working from a 13-shot list built by scene detection and confirmed against a contact sheet.

04 — The comparison you asked for

Pillow vs Remotion

The Aventador base cut was built twice from the same cue.json, so the pipelines could be judged on equal footing. Measured over the same 421 frames.

 Pillow + ffmpegRemotion
Render~64s, single process~2 min at concurrency 2
Output6.9 MB12.7 MB at defaults
Install3 Python packages255 npm packages · 517 MB
PreviewRender a stillLive studio, hot reload
LayoutAbsolute pixels in PythonCSS, browser text engine
Runtimeffmpegffmpeg and Chromium
Pillow wins on speed, weight and exact pixel control — better for a repeatable house format. Remotion wins on iteration: the studio previews the timeline live, and a new component is a React component rather than a set of paste coordinates. The two outputs are visually equivalent but not pixel-identical — at t=2.6 the hook block sits within 26px of position and 5px of height. Two text engines, and both causes are documented in the code.

05 — What is now written down

The rules it cost us

Recorded in 09-campaign-ads/HOUSE-STYLE.md, and made findable — the ads folder was missing from the kit README's map entirely. Each of these cost a render or a rebuild.

Never stand the accent stripe on end. Its black segment reads as a designed gap horizontally, and as a broken line vertically. The rail layout uses solid red.
The ticker sits at y=0.775. Any layout placing a lockup near it collides. Rail sits at 0.688, centred at 0.845.
Measure the footage before choosing a band. Sample mean brightness where each element will sit, across the whole clip, before committing to a treatment.
Callouts need a shot that lasts. A leader line anchored to the car is invalid at the next cut. Fine on the 765LT; dropped on the Aventador.
Only put on screen what the shop can substantiate. The 765LT's tuned column is invented for layout and flagged as replace-before-publish. The Aventador carries no horsepower figures at all — there is no dyno sheet for that car.

Approved treatments

hud and centred are both signed off and equal — picked per job, on the footage. What was approved in hud is the treatment itself, independent of whether the type band holds a spec counter or a static build sheet.
