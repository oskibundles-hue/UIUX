# agentmesh head-to-head bench, 2026-09-30 (cloud v1.3)

Omarie wanted real data to settle which model each NQ OS agent runs on. `run`, `facts` and `second` were
measured earlier the same day (see MESH.md). This bench covers the other five. `build`, `check`, `fix` and
`story` each did the same real job on Sonnet and on Opus; `label` ran once. Effort came from each agent
file and was not changed. One agent ran at a time, and no job was re-run.

**Rule:** keep Sonnet if its result is as right as Opus's (same known-answer outcome, no real defect
missed), because it's faster and lighter on the weekly limit. Choose Opus if Opus got something right that
Sonnet missed. For `story`, Omarie's blind pick decides.

## Results

`tokens` is `subagent_tokens` from the Agent tool result. The build job found that this figure is **not a
run total**: it is the run's last message only (its context plus its output). The last column is the
run's summed input + cache + output from the transcripts, read with the Opus build's `agent_usage.py`.
Output is a lower bound, because the transcripts hold only mid-stream records for every message but the
last.

### Fix

Planted bug: `tf = n["tf"].get(w, 0)` → `get(w, 1)` in both copies of `recall.py`; eval dropped to 30/33.
Each fixer got only the symptom. Both restored `0`, and both files now match the repo copy byte for byte.

### Story (blind)

The two sets went to Omarie as Set A and Set B in random order (A was Sonnet). He answered "you pick seems
the same", so the lead decided on the evidence: the options were close, but Sonnet's lead flag was wrong
and Opus caught two things Sonnet didn't.

## Decisions

| class | v1.3 cell | decision | why |
|---|---|---|---|
| label | sonnet/low | **sonnet/low** (keep) | 58/58, 16 s |
| build | sonnet/medium | **opus/medium** (change) | only Opus found the real defect in the spec (mid-stream usage); Sonnet shipped a wrong column |
| check | opus/medium | **opus/medium** (keep) | Opus caught a real defect Sonnet's check passed |
| fix | opus/medium | **sonnet/medium** (change) | same known answer, same tokens, half the time |
| story | opus/high | **opus/high** (keep) | Omarie called it even; Sonnet's set carried a wrong claim |

Trade-off noted: `build` and `check` are now the same model, so the quality gate is no longer a different
model from the builder. The facts panel (`facts` on Opus, `second` on Sonnet) still splits models.

Final cloud v1.3 cells: run sonnet/low, label sonnet/low, build opus/medium, fix sonnet/medium, check
opus/medium, story opus/high, facts opus/high (floor), second sonnet/high (floor); plate off.
