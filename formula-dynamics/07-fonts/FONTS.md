# Fonts

## Bundled

### Bebas Neue — primary / headlines
`BebasNeue-Regular.ttf` · SIL Open Font License 1.1 (`OFL-BebasNeue.txt`)

Free for commercial use, including embedding in video. This is the face used in
every generated overlay in this kit.

Uppercase only by design — there is no lowercase. Set headlines in caps with a
little letter-spacing (2–4%).

**Install**
- **macOS** — double-click the `.ttf`, click *Install Font*
- **Windows** — right-click the `.ttf`, *Install for all users*
- **CapCut mobile** — CapCut can't load system fonts on iOS/Android. Use the
  pre-rendered title cards and lower thirds in `../03-overlays/`, or pick
  CapCut's closest built-in (see below).

## Not bundled

### Neuropol X — performance / accent
The squared, technical italic used for the word "PERFORMANCE" in the logo.

**Neuropol X is a commercial typeface and cannot be redistributed**, so it isn't
in this repo. Licence it from the foundry (Typodermic) if you want to set new
text in it.

**You mostly don't need it.** The word "PERFORMANCE" is already part of the
logo artwork in `../02-logos/`, which is vector and scales to any size. Neuropol
X is only needed to set *new* words in that style.

Where the kit needs that look, it approximates it with italicised Bebas Neue —
that's what you see on the red line of the title cards.

## Substitutes

If Bebas Neue isn't available, in order of preference:

| Substitute | Where | Notes |
|---|---|---|
| **Oswald** | Google Fonts, free | Closest free match |
| **Anton** | Google Fonts, free | Heavier, works for big titles |
| **Archivo Narrow** | Google Fonts, free | More neutral |
| Arial Narrow Bold | System | Last resort |

**In CapCut**, the closest built-ins are anything labelled *Condensed*,
*Compressed*, or *Impact*-like. Set it once, then reuse that text style — CapCut
lets you copy a text style between clips.

## Type rules

- Headlines: **caps**, Bebas Neue, 2–4% letter-spacing
- Emphasis: one word in red `#FE0F13` — never a whole line
- Never stretch or condense type to fit. Change the size instead.
- Never outline headline type in red. White with a black outline or shadow.
- Two weights max on screen at once. Usually one is enough.
